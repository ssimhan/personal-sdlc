Kent Beck — still the most useful framework in software
1
Make it work
Happy path. Success criteria met. What most people call an MVP.
2
Make it right
Edge cases, cleaner structure. Something you'd show someone else.
3
Make it fast
Integrations, scale, optimization. This is how toys become products.
